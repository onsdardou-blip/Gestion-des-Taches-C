# Gestion des tâches en C

## Description

Ce projet consiste à développer une application en langage C permettant de gérer une liste de tâches ainsi que les opérateurs associés à chaque tâche.

Il a été réalisé dans le cadre de ma première année en Informatique de Gestion.

## Objectifs du projet

- Apprendre à manipuler les listes chaînées.
- Utiliser les structures et les pointeurs.
- Organiser un programme à l'aide de fonctions.
- Manipuler et gérer les données des tâches.
- Comprendre l'allocation dynamique de mémoire.

## Fonctionnalités principales

1. Ajouter une nouvelle tâche.
2. Afficher la liste des tâches.
3. Calculer la durée totale des tâches.
4. Insérer une tâche avant une autre tâche du même type.
5. Associer un opérateur à une tâche.
6. Supprimer les tâches selon leur type.
7. Remplacer un opérateur par un autre.
8. Trier les tâches par durée décroissante selon leur type.
9. Évaluer l'efficacité d'un opérateur en fonction de sa durée de travail et de la séquence des tâches.

## Technologies utilisées

- **Langage :** C
- **Structures de données :** `struct`
- **Listes chaînées**
- **Pointeurs**
- **Allocation dynamique de mémoire**
- **Fonctions et récursivité**

## Compilation et exécution

### Compilation

```bash
gcc main.c -o gestion_taches
```

### Exécution

```bash
./gestion_taches
```
